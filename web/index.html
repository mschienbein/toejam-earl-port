Display shaders are opt-in GPU effects. Smooth uses soft bilinear; CRT adds scanlines and an RGB mask to the selected filter, with optional curvature. Pixel shape and scaling are unchanged.

Native (NTSC) keeps the original display shape; Square pixels keeps the raw framebuffer shape. Controls and remapping

Default player 1: arrow keys, Z / X / C, Enter. Default player 2: W / S / A / D, J / K / L, Right Shift. The current assignments below can be changed with keyboard or mouse. F toggles fullscreen; Escape exits fullscreen or cancels an assignment. Tab always moves focus. Connect player 2 above for its keyboard, or assign it a gamepad.

Before changing a gamepad binding, center sticks and release controls, then activate its assignment and press a button or move an axis. Standard and non-standard Gamepad API devices can be assigned. A non-standard device may need every action remapped. Device numbers distinguish identical names. Explicit choices pin the browser’s device slot and stay unavailable rather than switching pads; if reconnection changes that slot, select the device again. Mappings are retained.

Playtest reports

Crashes are saved locally in this browser’s IndexedDB, never uploaded. Reports contain the build/commit, browser/OS, ROM revision and SHA-1 only (never ROM bytes or compiled code), settings, error/stack, last completed frame/state and controller-only inputs. The input ring holds 216,000 console frames (about one hour at 60 Hz). It restarts on reset/import; while it fits, the existing tje-session recording is continuous from power-on. After overflow the bundle explicitly contains a non-replayable input tail instead of claiming a power-on recording.

This consent is remembered for future crashes. Turn it off to stop collecting pixels. Notes and settings may contain personal details; review the downloaded bundle before sharing it.

Never attach your ROM or generated-code cache. Browser storage can be evicted; download reports you want to keep.

Developers can replay a complete downloaded bundle with toejam-earl --rom /private/rev02.bin --replay-report report.tje-report.json. The developer must supply the matching original cartridge. The CLI checks the captured frame/PC/clock/player summary; an unfinished frame’s input is included to reproduce the error. Overflowed tails cannot replay deterministically. The transport-independent bundle is the extension point for a future explicitly approved upload service; none exists now.

Privacy and browser requirements

Use an up-to-date browser on HTTPS (or localhost). WebGPU is preferred; WebGL 2 is the automatic fallback. Audio starts on Play. A hidden tab pauses the game and releases held keys; returning attempts to resume its audio and game automatically. If the browser requires another gesture, Play remains available with a clear message. Manually paused games stay paused.

Audio blocks are transferred to an AudioWorklet without SharedArrayBuffer or cross-origin-isolation headers. Volume, display options and both players’ mappings are versioned in localStorage. ROM data is never stored in localStorage. Forget removes the IndexedDB cartridge and all its generated code configurations, then reloads an empty session without deleting settings.

The engine generates each original instruction as a timed WebAssembly continuation, sharing the VDP, audio chips and original Z80 sound program. Generated code is bound to the verified ROM, engine version and clock configuration; its cache is checked before use. Nothing generated from your cartridge is downloaded from a server or included in this static page.
